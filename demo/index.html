How the audit works

1

Use your working hours

The browser checks each local time using timezone rules built into your browser.

2

Find clock-change dates

The report marks the first enabled working window after each clock change. It also marks times that repeat or do not occur.

3

Compare published times

Import a UTC CSV or ICS file. The report finds missing, extra, shifted, and duration-changed slots.

How repeated and missing local times work

Repeated local times are marked Review. The ICS file uses the earlier occurrence. Missing local times are marked Invalid and omitted from ICS.
