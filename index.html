How it works

How the audit works

1

Use your working hours

The browser checks each local time using the selected timezone’s IANA rules.

2

Find clock-change dates

The results show the first working window after an offset change. They also mark times that repeat or do not occur.

3

Compare booking times

Export an expected availability file. Compare it with your booking page before you publish hours.

How repeated and missing local times work

Repeated local times are marked Review. The ICS file uses the earlier occurrence. Missing local times are marked Invalid and omitted from ICS.
